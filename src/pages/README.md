# pages

Готовые страницы-экраны, по одной папке на маршрут:

- `login` — экран авторизации (/#/login)
- `no-access` — «нет доступа к дашборду ДТП»
- `data-error` — ни одна база не отдала данные
- `overview` — «Обзор» (/#/)
- `motorcade` — «Статистика по автоколонне» (/#/motorcade)
- `analytics` — «Аналитика» (/#/analytics)

Страница просто собирает виджеты и фичи в layout, сама почти не содержит логики. Именно этот слой — основная зона работы разработчиков экранов.
