# shared

Переиспользуемый код без привязки к бизнес-логике проекта:

- `api/` — HTTP-клиент, работа с SESSIONID, базовые методы запросов к api-v2 (переносится из Dashboard_tochki_rosta_TypeScript на Этапе 2)
- `config/` — константы (BASE_URL, AppCode), чтение DB_GUID из адресной строки, классификация причин ДТП (`accidentCauses.ts`, ТЗ §4.2)
- `lib/` — утилиты (форматирование чисел ru-RU, работа с датами/периодами)
- `ui/` — базовые UI-компоненты общего назначения: KpiCard, ChartWrapper, DataTable, Modal, Skeleton, EmptyState, ErrorState — переносятся из первого дашборда по мере необходимости

Это самый нижний слой — от него зависят все остальные, а он ни от кого не зависит.
