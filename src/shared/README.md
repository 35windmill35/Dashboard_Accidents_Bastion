# shared

Переиспользуемый код без привязки к бизнес-логике проекта:

- `api/` — HTTP-клиент, работа с SESSIONID, базовые методы запросов к api-v2
- `config/` — константы (BASE_URL, AppCode), чтение DB_GUID из адресной строки
- `lib/` — утилиты (форматирование, лимит параллельности запросов)
- `ui/` — базовые UI-компоненты общего назначения: PasswordInput, Skeleton, ErrorState и т.д., по мере необходимости переносятся из первого дашборда

Это самый нижний слой — от него зависят все остальные, а он ни от кого не зависит.
