# Дашборд ДТП — ТОО «BLG»

Аналитический дашборд по дорожно-транспортным происшествиям автобусного парка компании: автоколонны **Павлодар** и **Алматы**.

Построен на данных из файла `Дашборд_ДТП_аналитика.xlsx` (1184 инцидента, период январь 2025 — сентябрь 2026).

## Возможности

- Ключевые показатели (KPI): количество ДТП, сумма ущерба, сумма и доля возмещения, средний ущерб на инцидент, структура причин.
- Фильтры: автоколонна (Все / Алматы / Павлодар) и произвольный период дат.
- Структура причин ДТП — графики по категориям.
- Сравнение автоколонн (с явным указанием разного охвата данных — см. предупреждение ниже).
- Топ-10 водителей и Топ-10 автобусов по количеству ДТП с раскрывающейся детализацией по каждому инциденту.
- Финансовый анализ: ущерб/возмещение по категориям, динамика по месяцам, % возмещения.
- Динамика ДТП по месяцам в разбивке по автоколоннам.
- Автоматические управленческие рекомендации на основе текущих данных (реагируют на фильтры).
- Тёмная/светлая тема, экспорт в PDF (печать страницы).

## ⚠️ Важное ограничение данных

Данные по автоколоннам имеют разный охват:

- **Алматы** — 984 из 984 ДТП в системе (100% охват).
- **Павлодар** — выборка **200 из 1448** ДТП (≈13.8% охвата).

Поэтому **абсолютные** показатели (количество ДТП, суммы ущерба) между автоколоннами напрямую не сравниваются. Корректны для сравнения только **относительные** показатели: доли причин, средний ущерб на 1 ДТП, доля возмещения. Дашборд явно отображает это предупреждение.

## Структура проекта

```
index.html            — разметка страницы
assets/style.css       — стили (светлая/тёмная тема)
assets/app.js          — логика: фильтры, расчёты, графики (Chart.js)
assets/data.json       — данные (1184 инцидента), собраны из исходного xlsx
assets/vendor/         — локальная копия Chart.js (без внешних CDN-зависимостей)
```

## Как посмотреть локально

Открыть `index.html` напрямую в браузере нельзя (запрос к `data.json` блокируется политикой браузера) — нужен локальный сервер:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/`.

## Обновление данных

Чтобы обновить дашборд новыми данными, пересоберите `assets/data.json` из свежего xlsx (сохраняя те же поля: `id, d, fleet, driver, bus, brand, cat, sub, damage, reimb, month`) и замените файл — остальной код не требует изменений.
