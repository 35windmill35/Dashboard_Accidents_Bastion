# entities

Бизнес-сущности проекта: Accident (запись о ДТП), Motorcade (автоколонна), User (сессия, список баз, права).

Здесь — MobX-сторы конкретных сущностей и их типы (`entities/accident/model/types.ts` — см. ТЗ §7). Это слой, который знает «что такое ДТП» или «что такое автоколонна», но не знает, как это нарисовано на конкретном экране.
