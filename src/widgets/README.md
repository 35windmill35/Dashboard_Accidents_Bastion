# widgets

Крупные самостоятельные блоки интерфейса, собранные из нескольких фич/сущностей: боковое выдвигающееся меню и шапка с фильтрами, блок KPI-карточек, блок графиков, сводная таблица и т.д.

Виджет знает, как расположить и связать несколько мелких частей, но не занимается низкоуровневой логикой запросов.
